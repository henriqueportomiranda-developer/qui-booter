# 🚀 Qui-Booter

O **Qui-Booter** é a ferramenta oficial da **Qui Enterprise** desenvolvida para facilitar e agilizar a criação de pendrives bootáveis diretamente no macOS.

## 💻 Compatibilidade
* **Plataforma:** macOS (11.0 Big Sur ou superior)
* **Arquitetura:** Universal (Compatível com Macs Intel e Apple Silicon M1, M2, M3, M4+)

## 📥 Como Baixar e Instalar
1. Vá até a aba **Releases** (Lançamentos) aqui no lado direito da página.
2. Baixe o instalador mais recente (`.pkg`).
3. Dê um duplo clique no arquivo baixado e siga os passos na tela.
